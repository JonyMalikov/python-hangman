# python-hangman

Простая консольная игра "Виселица" на Python.

## Описание

Это реализация классической игры "Виселица", где игрок должен угадывать буквы в слове на русском языке, чтобы не допустить появление полного ASCII-арта виселицы.

### Особенности
- Поддержка русского языка.
- Подсказки за количество попыток.
- Отображение состояния виселицы после каждой ошибки.
- Возможность угадать слово целиком.

## Как играть

1. Запустите скрипт `hangman.py`.
2. Вводите по одной букве или слово целиком.
3. У вас есть 6 попыток до проигрыша.
4. Используйте `?`, чтобы получить подсказку (стоимость — 2 попытки).

## Запуск

```bash
python hangman.py
```

## Слова

Игра использует предопределённый список слов на русском языке, включающий термины из области программирования и общего пользования.
